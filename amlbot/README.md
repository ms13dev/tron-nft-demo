# AMLBot — тестовая коллекция в TRON Shasta

Название новой коллекции в контракте: **AMLBot**. Символ: **AMLBOT**.
Индивидуальное название NFT в обоих JSON: **AML Verification Request** — без номера в поле `name`.
Это отдельные значения: кошелёк может показывать название коллекции и название NFT в разных разделах.

Файлы подготовлены для отдельного контракта в Shasta. Адрес будет указан после подтверждения развёртывания.
Выпуск NFT #0 планируется после публикации и проверки метаданных. Для #1 подготовлены только метаданные; NFT #1 не выпущен.
Наличие JSON-файла само по себе не означает, что соответствующий токен существует в блокчейне.

`description` явно обозначает тест в Shasta и содержит адрес сайта обычным текстом.
В `attributes` указаны `Project: AMLBot` и `Network: Shasta`.
